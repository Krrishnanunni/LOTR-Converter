# LOTR Converter

LOTR Converter is a beautifully crafted SwiftUI app that lets you explore and convert between the various currencies from the world of "The Lord of the Rings." Featuring a smooth, interactive interface, the app makes it fun and easy to learn the value of copper pennies, silver shillings, gold pieces, and more.

## Features

- **Intuitive Currency Exchange:** Instantly convert between Middle-earth currencies by entering an amount on either side.
- **Rich Visuals:** Gorgeous artwork and themed UI immerse you in the world of LOTR.
- **Currency Selection:** Tap on either currency name or icon to change it with a simple picker.
- **TipKit Integration:** Helpful tips guide new users through currency selection.
- **Responsive Design:** Optimized for all devices, with beautiful layout and keyboard handling.
- **Informative Sheets:** Access more information about the exchange rates and the currency system through an info modal.

## Getting Started

1. Clone the repository to your local machine.
2. Open the project in Xcode.
3. Build and run on your desired device or simulator.
